# RoyalWrist 

RoyalWrist is a modern, responsive e-commerce front-end for a premium watch retailer, built with React. It showcases a curated catalog of branded watches (Men, Women, Kids) with category filtering, product cards, and a full storefront experience - from hero banner to contact/login sections.

## Features

- **Hero section** with featured product highlight and CTA buttons
- **Browse by style** - quick category navigation (Men, Women, Kids, Hot Selling)
- **Hot Selling Watches** grid with category filter tabs (All / Men / Women / Kids)
- **Product cards** with price, rating, wishlist icon, and quick-add button
- **About Us** section with brand story
- **Contact form** for inquiries
- **Member login** section with saved orders/offers access
- **Fully responsive** layout across devices

## Tech Stack

- **React** (component-based UI)
- **Tailwind CSS** for styling (custom, responsive design)


## Getting Started

```bash
# Clone the repository
git clone https://github.com/FrontendDevSQ/RoyalWrist.git

# Navigate into the project
cd RoyalWrist

# Install dependencies
npm install

# Start the development server
npm start
npm run dev
```
